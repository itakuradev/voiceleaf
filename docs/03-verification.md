# 3. 補足と未確認事項

## AC-07（3分での自動終了）

`MAX_RECORDING_SECONDS` を一時的に 12 秒へ変更し、上限到達時に録音が自動停止して
「要約しています」へ遷移することを確認した。定数を 180 に戻した状態での実測は行っていない。

自動終了は経過秒数と定数の比較のみで判定しているため、値による挙動の差はない。
実測が必要な場合は、3分間の録音を1回実施すれば足りる。

## AC-18（一時音声ファイルの削除）

Expo Go は `run-as` によるアプリ内ファイルの直接参照ができないため、
ステップ2の検証画面で「削除実行 → ファイルが存在しないこと」をアプリ側から確認した。
本実装では成功・失敗・中断のすべての経路で `finally` から削除しており、
さらにアプリ起動時にもキャッシュ内の残存ファイルを削除している。

## FN-10（要約内の見出し生成）

複数の話題を含む長い音声が必要なため、見出しが実際に生成された状態での表示確認は未実施。
`SummaryText` は `## 見出し` と空行のみを解釈する実装で、
想定外の記法が来た場合もプレーンテキストとして表示されるため破綻はしない。

# 4. 検証中に判明した事項

| 内容 | 対応 |
| --- | --- |
| `react-native-reanimated` が Expo Go 上でJSスレッドをSIGSEGVクラッシュさせる | 依存から除去し、標準の `Animated` API を使用（設計書 12章 #17） |
| `gemini-2.5-flash` 系が新規ユーザーへの提供を終了しており404になる | `gemini-3.6-flash` へ変更（設計書 12章 #7） |
| デザイン画像から矩形で切り出したイラストに画面のベゼルが写り込み、背景色差で輪郭が見えた | 背景透過PNGを別途用意し、不透明領域でトリミング（設計書 12章 #18） |
